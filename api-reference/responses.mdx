---
title: "Responses"
description: "Create and manage model responses using the OpenAI Responses API through the Portkey gateway."
---

The Responses API is compatible with the OpenAI Responses API. It allows you to create stateful model interactions where each response can reference previous ones via an ID. Portkey proxies these requests to the configured provider.

<Note>
  The Responses API is currently supported for providers that implement the OpenAI Responses API contract. Check your provider's documentation to confirm compatibility.
</Note>

## Create a model response

`POST /v1/responses`

Creates a new model response. The request body is forwarded to the provider.

### Request

<ParamField header="x-portkey-provider" type="string" required>
  The provider to route the request to (e.g. `openai`).
</ParamField>

<ParamField header="x-portkey-api-key" type="string" required>
  Your Portkey API key or provider API key.
</ParamField>

<ParamField body="model" type="string" required>
  The model to use for the response (e.g. `gpt-4o`).
</ParamField>

<ParamField body="input" type="string | array" required>
  The input for the model. Can be a plain text string or an array of message objects.
</ParamField>

<ParamField body="previous_response_id" type="string">
  The ID of a previous response to continue from. Enables multi-turn stateful conversations.
</ParamField>

<ParamField body="instructions" type="string">
  System-level instructions to guide the model's behavior.
</ParamField>

<ParamField body="tools" type="array">
  A list of tools the model may call. Follows the OpenAI tool definition format.
</ParamField>

<ParamField body="stream" type="boolean" default="false">
  Whether to stream the response. When `true`, the gateway returns server-sent events.
</ParamField>

<ParamField body="max_output_tokens" type="number">
  Maximum number of tokens in the output.
</ParamField>

### Response

<ResponseField name="id" type="string">
  Unique identifier for the response.
</ResponseField>

<ResponseField name="object" type="string">
  Always `response`.
</ResponseField>

<ResponseField name="model" type="string">
  The model that generated the response.
</ResponseField>

<ResponseField name="status" type="string">
  Response status. Values: `completed`, `in_progress`, `failed`, `cancelled`.
</ResponseField>

<ResponseField name="output" type="array">
  Array of output items generated by the model.
</ResponseField>

<ResponseField name="usage" type="object">
  <Expandable title="properties">
    <ResponseField name="input_tokens" type="number">
      Number of tokens in the input.
    </ResponseField>
    <ResponseField name="output_tokens" type="number">
      Number of tokens in the output.
    </ResponseField>
    <ResponseField name="total_tokens" type="number">
      Total tokens used.
    </ResponseField>
  </Expandable>
</ResponseField>

<CodeGroup>

```bash cURL
curl https://your-gateway.example.com/v1/responses \
  -X POST \
  -H "Content-Type: application/json" \
  -H "x-portkey-api-key: YOUR_API_KEY" \
  -H "x-portkey-provider: openai" \
  -d '{
    "model": "gpt-4o",
    "input": "Explain quantum entanglement in simple terms."
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    base_url="https://your-gateway.example.com/v1",
    api_key="YOUR_API_KEY",
    default_headers={
        "x-portkey-provider": "openai",
    },
)

response = client.responses.create(
    model="gpt-4o",
    input="Explain quantum entanglement in simple terms.",
)

print(response.id, response.status)
```

```javascript JavaScript
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://your-gateway.example.com/v1",
  apiKey: "YOUR_API_KEY",
  defaultHeaders: {
    "x-portkey-provider": "openai",
  },
});

const response = await client.responses.create({
  model: "gpt-4o",
  input: "Explain quantum entanglement in simple terms.",
});

console.log(response.id, response.status);
```

</CodeGroup>

## Get a response

`GET /v1/responses/:id`

Retrieves a previously created model response by its ID.

### Request

<ParamField path="id" type="string" required>
  The ID of the response to retrieve.
</ParamField>

<ParamField header="x-portkey-provider" type="string" required>
  The provider to route the request to.
</ParamField>

<ParamField header="x-portkey-api-key" type="string" required>
  Your Portkey API key or provider API key.
</ParamField>

### Response

Returns the response object. See [Create a model response](#create-a-model-response) for the full field list.

<CodeGroup>

```bash cURL
curl https://your-gateway.example.com/v1/responses/resp-abc123 \
  -H "x-portkey-api-key: YOUR_API_KEY" \
  -H "x-portkey-provider: openai"
```

```python Python
response = client.responses.retrieve("resp-abc123")
print(response.status)
```

```javascript JavaScript
const response = await client.responses.retrieve("resp-abc123");
console.log(response.status);
```

</CodeGroup>

## Delete a response

`DELETE /v1/responses/:id`

Deletes a stored model response.

<Warning>
  Deletion is permanent. Any response chain built on top of this response via `previous_response_id` may become incomplete.
</Warning>

### Request

<ParamField path="id" type="string" required>
  The ID of the response to delete.
</ParamField>

<ParamField header="x-portkey-provider" type="string" required>
  The provider to route the request to.
</ParamField>

<ParamField header="x-portkey-api-key" type="string" required>
  Your Portkey API key or provider API key.
</ParamField>

### Response

<ResponseField name="id" type="string">
  The ID of the deleted response.
</ResponseField>

<ResponseField name="object" type="string">
  Always `response`.
</ResponseField>

<ResponseField name="deleted" type="boolean">
  `true` if the response was successfully deleted.
</ResponseField>

<CodeGroup>

```bash cURL
curl https://your-gateway.example.com/v1/responses/resp-abc123 \
  -X DELETE \
  -H "x-portkey-api-key: YOUR_API_KEY" \
  -H "x-portkey-provider: openai"
```

```python Python
result = client.responses.delete("resp-abc123")
print(result.deleted)
```

```javascript JavaScript
const result = await client.responses.delete("resp-abc123");
console.log(result.deleted);
```

</CodeGroup>

## List response input items

`GET /v1/responses/:id/input_items`

Returns the input items that were included in a response. This is useful for inspecting the full context that was sent to the model.

### Request

<ParamField path="id" type="string" required>
  The ID of the response whose input items to list.
</ParamField>

<ParamField header="x-portkey-provider" type="string" required>
  The provider to route the request to.
</ParamField>

<ParamField header="x-portkey-api-key" type="string" required>
  Your Portkey API key or provider API key.
</ParamField>

<ParamField query="limit" type="number" default="20">
  Maximum number of input items to return.
</ParamField>

<ParamField query="after" type="string">
  Cursor for pagination.
</ParamField>

### Response

<ResponseField name="object" type="string">
  Always `list`.
</ResponseField>

<ResponseField name="data" type="array">
  Array of input item objects representing the messages and context sent in the request.
</ResponseField>

<ResponseField name="has_more" type="boolean">
  Whether additional input items are available.
</ResponseField>

<CodeGroup>

```bash cURL
curl https://your-gateway.example.com/v1/responses/resp-abc123/input_items \
  -H "x-portkey-api-key: YOUR_API_KEY" \
  -H "x-portkey-provider: openai"
```

```python Python
items = client.responses.input_items.list("resp-abc123")
for item in items.data:
    print(item)
```

```javascript JavaScript
const items = await client.responses.inputItems.list("resp-abc123");
for (const item of items.data) {
  console.log(item);
}
```

</CodeGroup>
