The **MCP Gateway** provides a centralized control plane for managing [Model Context Protocol (MCP)](https://modelcontextprotocol.io) servers across your organization.

<Info>
  MCP Gateway is a feature of [Portkey Cloud](https://app.portkey.ai) and enterprise deployments. It is documented fully at [portkey.ai/docs/product/mcp-gateway](https://portkey.ai/docs/product/mcp-gateway). This section provides an overview of the capabilities.
</Info>

## What is MCP?

MCP (Model Context Protocol) is an open protocol that lets AI clients connect to external tools and data sources — called **MCP servers**. When an AI assistant needs to query a database, read a file, or call an API, it does so through an MCP server.

Without a gateway, every client authenticates separately to every MCP server. There is no central place to manage access, audit tool calls, or revoke permissions.

## How it works

```
MCP Client (Claude Desktop, Cursor, VS Code, ...)
        │
        │  authenticated request
        ▼
  Portkey MCP Gateway
        │  ├─ authenticates the user
        │  ├─ checks access policy
        │  ├─ logs the tool call
        │  └─ forwards identity headers
        ▼
  Your MCP Server (filesystem, GitHub, postgres, ...)
```

The gateway is transparent to both the client and server. Clients connect to a single Portkey endpoint; servers receive requests with a verified shared secret and user identity headers.

## Compatible clients

Works with any MCP-compatible client:

- **Claude Desktop** — Anthropic's desktop application
- **Cursor** — AI-powered code editor
- **VS Code** — with the Continue extension or similar MCP clients
- **Custom clients** — any application implementing the MCP protocol
